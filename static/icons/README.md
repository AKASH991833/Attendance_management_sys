# PWA Icons Directory

Place the following icon files in this directory:

- `icon-72x72.png` (72x72 pixels)
- `icon-96x96.png` (96x96 pixels)
- `icon-128x128.png` (128x128 pixels)
- `icon-192x192.png` (192x192 pixels)
- `icon-512x512.png` (512x512 pixels)

## Creating Icons

You can create icons using:
1. **Figma** - Design and export as PNG
2. **Canva** - Free online design tool
3. **RealFaviconGenerator** - https://realfavicongenerator.net/
4. **Any image editor** - Create a 512x512 image and resize

## Recommended Icon Design

- Use a graduation cap or book icon
- Primary color: #4f46e5 (indigo)
- Background: Transparent or white
- Simple, recognizable at small sizes

For development, the app will work without icons, but PWA features require them for production.
